# Problem Solving

My daily JavaScript problem solving practice. Each day has its own folder with solutions written using plain loops and logic, without shortcuts like `reduce()` or `reverse()`.

## Folder Structure

```
Problem_Solving/
├── Day_1/      Set 1 solutions (Problems 1-10)
├── Day_2/      Set 2 solutions (Problems 11-20)
│   ├── day2.js
│   └── JavaScript_Problem_Solving_Set2.pdf
└── README.md
```

## How I Solve Each Problem

1. Write the problem, input and output in my own words
2. Solve a small example by hand
3. Write the algorithm and pseudocode
4. Dry run in a table
5. Think about edge cases (empty input, one element, negatives)
6. Write the JavaScript code and run the test cases

## How to Run

Make sure [Node.js](https://nodejs.org) is installed, then:

```
cd Day_2
node day2.js
```
